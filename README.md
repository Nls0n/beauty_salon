# BeautySalon Management System

Полноценная система управления бьюти-салоном, разработанная на стеке **Django + PostgreSQL**.

Проект позволяет управлять сотрудниками, услугами, клиентами и записью на сеансы через удобный веб-интерфейс.

---

# Возможности

## Основной функционал

- Полный CRUD для:
  - мастеров
  - услуг
  - клиентов
  - записей

- Интеллектуальный поиск услуг через Django ORM

- Аналитика и агрегация данных:
  - `COUNT`
  - `SUM`
  - статистика на стороне БД

- Административная панель Django

---

# Технологический стек

| Технология | Описание |
|---|---|
| Python 3.12+ | Основной язык |
| Django | Backend framework |
| PostgreSQL | База данных |
| Docker | Контейнеризация |
| docker-compose | Управление инфраструктурой |
| uv | Менеджер зависимостей |
| Ruff | Линтер и форматтер |

Проект построен на реляционных связях между сущностями:

# Установка и запуск

## 1. Клонирование репозитория

```bash
git clone <your-repository-url>
cd beauty_salon
```

---

## 2. Запуск инфраструктуры

Поднимает PostgreSQL в Docker-контейнере:

```bash
make install
```

---

## 3. Применение миграций

```bash
make migrate
```

---

## 4. Наполнение тестовыми данными

```bash
make seed
```

---

## 5. Запуск сервера

```bash
make run
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

# Makefile команды

## Инфраструктура и запуск

| Команда | Описание |
|---|---|
| `make up` | Поднять БД и запустить сервер |
| `make install` | Запустить docker-compose |
| `make run` | Запуск Django сервера |

---

## Работа с базой данных

| Команда | Описание |
|---|---|
| `make migrations` | Создать миграции |
| `make migrate` | Применить миграции |
| `make seed` | Наполнить БД тестовыми данными |
| `make superuser` | Создать администратора |

---

## Качество кода

| Команда | Описание |
|---|---|
| `make ruff` | Проверка линтером |
| `make format` | Форматирование кода |
| `make fix` | Автоисправление ошибок |
